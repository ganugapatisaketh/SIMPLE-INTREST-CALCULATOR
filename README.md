# Simple Interest Calculator

A small bash script that calculates **simple interest** given Principal, Rate, and Time.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

## How to run (on your computer)
1. Clone the repository:
   ```
   git clone https://github.com/ganugapatisaketh/simple-interest-calculator
   cd simple-interest-calculator
   ```
2. Make the script executable:
   ```
   chmod +x simple-interest.sh
   ```
3. Run the script:
   ```
   ./simple-interest.sh
   ```
4. Follow the prompts: enter Principal, Rate (percent), and Time (years).

## Example
If you enter:
- Principal: `1000`
- Rate: `5`
- Time: `2`

The script will output:
```
Simple Interest = 100.00
```
